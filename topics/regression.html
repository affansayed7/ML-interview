§3 · Regression

Linear
Regression

The simplest model in ML — and the one interviewers use to check whether you actually understand loss functions, gradient descent, and assumptions, or just memorized sklearn.fit().

1. The hypothesis

Linear regression fits a straight line (or hyperplane, in higher dimensions) through the data that best predicts a continuous target $y$ from features $x$.

Simple linear regression
$$ \hat{y} = \theta_0 + \theta_1 x $$
Multiple linear regression (vectorized)
$$ \hat{y} = X\theta \quad \text{where } X \in \mathbb{R}^{m \times n},\ \theta \in \mathbb{R}^{n} $$

$\theta_0$ is the intercept (bias) — the predicted value when every feature is zero. $\theta_1$ is the slope — how much $\hat{y}$ changes per unit change in $x$.

2. The cost function — why squared error?

We need one number that summarizes "how wrong" the line is across all points. Squaring each residual before averaging (rather than just averaging raw residuals) does two things: it makes every error positive so they don't cancel out, and it punishes large errors disproportionately more than small ones — a residual twice as large contributes four times the cost.

Mean Squared Error cost function
$$ J(\theta) = \frac{1}{2m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 $$
Where does the ½ come from? It's purely for convenience: when you differentiate $J(\theta)$ to run gradient descent, the power rule brings down a factor of 2, which cancels the $\frac{1}{2}$ cleanly. It doesn't change where the minimum is — just makes the derivative tidier.

The probabilistic justification (MLE view)

MSE isn't an arbitrary choice. If you assume the errors between your predictions and the true values are Gaussian-distributed noise, then finding the parameters that maximize the likelihood of observing your data turns out to be mathematically identical to finding the parameters that minimize the sum of squared errors. This is why squared error is the "natural" loss for regression — it falls directly out of assuming normally distributed residuals.

3. Gradient descent

Since $J(\theta)$ is convex (bowl-shaped) for linear regression, gradient descent is guaranteed to converge to the global minimum, not just a local one — provided the learning rate is chosen well. At each step, we nudge every parameter in the direction that reduces cost the fastest: the negative gradient.

Update rule (applied simultaneously to every θⱼ)
$$ \theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta) $$
Partial derivative for linear regression
$$ \frac{\partial J}{\partial \theta_j} = \frac{1}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)x_j^{(i)} $$

Learning rate ($\alpha$) controls step size. Too small and convergence is painfully slow; too large and you overshoot the minimum and can diverge entirely — the loss bounces around or explodes instead of decreasing.

Interview trap "Does gradient descent for linear regression ever get stuck in a local minimum?" — No. Because $J(\theta)$ is a convex quadratic bowl (one global minimum, no local dips), gradient descent always converges to the global optimum given a small enough learning rate. This is not true for neural networks, where the loss surface is non-convex.

4. The normal equation — a closed-form alternative

Gradient descent is iterative. But because the MSE cost function has a clean derivative, you can solve for the optimal $\theta$ directly in one step, with no learning rate and no iteration, by setting the gradient to zero and solving analytically.

Normal equation
$$ \theta = (X^T X)^{-1} X^T y $$

5. Assumptions of linear regression

These are a favorite interview list — violating them doesn't necessarily break the model, but it breaks the validity of your coefficient interpretations and confidence intervals.

  • Linearity — the relationship between features and target is actually linear.
  • Independence — residuals are independent of each other (a big issue in time-series data with autocorrelation).
  • Homoscedasticity — residuals have constant variance across all predicted values (no "funnel" shape).
  • Normality of residuals — errors are approximately normally distributed (matters most for small samples and confidence intervals, not prediction itself).
  • No multicollinearity — features aren't highly correlated with each other.

Multicollinearity

When two or more features are highly correlated with each other, the model can't reliably tell which one deserves credit for predicting the target — coefficients become unstable, can flip sign, and their individual interpretation becomes meaningless (even though overall predictions may still be fine). Detect it with the Variance Inflation Factor (VIF); a common rule of thumb is VIF > 5–10 signals a problem.

Variance Inflation Factor for feature i
$$ VIF_i = \frac{1}{1 - R_i^2} $$

where $R_i^2$ comes from regressing feature $i$ against all other features. Fixes: drop one of the correlated features, combine them, or use Ridge Regression (L2 regularization), which shrinks correlated coefficients together instead of letting them destabilize.

6. Evaluating the fit

R² (coefficient of determination)
$$ R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2} $$

$R^2$ tells you what fraction of the variance in $y$ your model explains. It ranges roughly 0 to 1 (can go negative for a truly terrible model) — but it has a well-known flaw: it never decreases when you add more features, even useless ones, which makes it a poor tool for comparing models with different numbers of features. Adjusted R² fixes this by penalizing extra features that don't earn their keep.

Interview Q&A

Derive the gradient of the MSE cost function with respect to θⱼ.

Start from $J(\theta) = \frac{1}{2m}\sum (h_\theta(x^{(i)}) - y^{(i)})^2$. Taking the partial derivative with respect to $\theta_j$ and applying the chain rule: the outer power rule brings down a 2 (which cancels the $\frac{1}{2}$), and the inner derivative of $h_\theta(x^{(i)}) = \theta_0 + \theta_1 x_1 + ...$ with respect to $\theta_j$ is just $x_j^{(i)}$. This leaves $\frac{\partial J}{\partial \theta_j} = \frac{1}{m}\sum (h_\theta(x^{(i)}) - y^{(i)}) x_j^{(i)}$ — the average residual, weighted by that feature's value.

Likely follow-up "Why do we update all θⱼ simultaneously rather than one at a time?" — because each partial derivative is computed using the same current θ; updating θ₀ first and then using the new θ₀ to compute θ₁'s gradient would compute an inconsistent, incorrect gradient direction.
Why use Mean Squared Error instead of Mean Absolute Error?

MSE is differentiable everywhere (MAE has an undefined/kinked derivative at zero), which makes gradient-based optimization smoother and more standard. MSE also penalizes large errors more heavily due to squaring, which is often desirable — but that's also its weakness: MSE is far more sensitive to outliers than MAE, since one large residual dominates the sum once squared.

Likely follow-up "When would you prefer MAE over MSE?" — when your data has significant outliers you don't want to dominate the loss, or when you want the metric to represent typical error in the same units without over-penalizing rare large misses.
When would you use the normal equation instead of gradient descent, and vice versa?

The normal equation is preferable when the number of features is small (roughly under a few thousand) — it gives an exact answer in one step with no learning rate to tune. Gradient descent is preferable when the number of features is large, since inverting $X^TX$ costs $O(n^3)$ and becomes computationally prohibitive, while gradient descent scales roughly linearly per iteration.

Likely follow-up "What if $X^TX$ isn't invertible?" — happens with multicollinearity or more features than samples; use the pseudoinverse, or apply regularization (Ridge), which is guaranteed invertible.
What is multicollinearity, why is it a problem, and how do you detect and fix it?

It's when two or more features are highly correlated with each other. It doesn't necessarily hurt overall prediction accuracy, but it makes individual coefficients unstable and hard to interpret — small changes in data can swing coefficients wildly or flip their sign, since the model can't cleanly attribute effect to one correlated feature versus another. Detect it via the Variance Inflation Factor (VIF); fix it by dropping/combining correlated features or applying Ridge regression, which shrinks correlated coefficients together rather than letting them destabilize.

Likely follow-up "Does multicollinearity affect the model's predictions, or just the coefficients?" — mainly the coefficients and their interpretability; overall predictive accuracy on the same data distribution is often largely unaffected.
What's the difference between R² and Adjusted R², and why does it matter?

R² measures the proportion of variance explained, but it mathematically can never decrease when you add more predictors — even completely irrelevant ones — because more parameters give the model more freedom to fit noise. Adjusted R² adds a penalty term based on the number of predictors relative to sample size, so it only increases when a new feature improves the fit more than would be expected by chance. This makes Adjusted R² the correct metric for comparing models with different numbers of features.

Likely follow-up "Can R² be negative?" — Yes, if the model fits worse than simply predicting the mean of y for every point (which would give R² = 0), R² can go negative.
What happens if you feed linear regression a target that has a non-linear relationship with the features?

The model will still fit a straight line/hyperplane — it has no way to represent curvature — so it systematically underfits, producing biased predictions and a residual plot that shows a clear pattern (e.g. a curve) rather than random scatter around zero. The fix is either polynomial regression (add $x^2, x^3$ terms), a feature transform (like log), or a fundamentally non-linear model.

Likely follow-up "How would you detect this from the residual plot alone?" — a residual plot with a visible curve or pattern (instead of a random cloud around zero) is the signature of a misspecified, too-simple model.
How sensitive is linear regression to outliers, and why?

Very sensitive, because the MSE loss squares each residual — a single far-away point contributes a disproportionately huge amount to the total cost, pulling the fitted line toward itself and away from the bulk of the data. This is a direct consequence of the squaring in MSE, and it's the classic argument for using robust alternatives (like Huber loss, or MAE) when your data has heavy-tailed noise or known outliers.

Likely follow-up "What's Huber loss, briefly?" — a hybrid that behaves like MSE for small residuals (smooth, differentiable) and like MAE for large residuals (linear, so outliers don't dominate) — the best of both.
Does linear regression require the target variable itself to be normally distributed?

No — a common misconception. The assumption is that the residuals (errors) are approximately normally distributed, not the raw target variable. This distinction matters because it's entirely possible to have a skewed target that still produces well-behaved, normal residuals once the linear relationship is accounted for.

Likely follow-up "Why does residual normality matter at all if we mainly care about predictions?" — it mainly matters for the validity of confidence intervals, hypothesis tests on coefficients, and p-values — point predictions themselves are relatively robust even when this assumption is mildly violated.
